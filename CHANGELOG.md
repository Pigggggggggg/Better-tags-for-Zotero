# Changelog

## 1.0.1

First prepared GitHub release, renumbered from the final private development build 2.2.2.

- Embedded tag navigation with Zotero's native item list and search.
- All/ANY selection, Ctrl/Alt multi-selection, nested groups and group ordering.
- Tag renaming, preset colors, item counts, saved combinations and batch editing.
- Title-based matching that adds only existing tags.
- Sidebar height ratio preserved when resizing the main window.
- Stale tag selection cleared when its final item disappears.
- Filter restrictions retained during native item updates and reader navigation.
- Attachments and notes remain collapsed by default for tag-only filtering.
- Fixed startup icon enlargement by applying toolbar geometry synchronously and setting embedded image dimensions before stylesheet loading.
- Public repository documentation, build scripts and MIT license packaging.

The add-on ID and preference keys are unchanged. Private 2.x users install this numerically lower public release manually. Automatic updates are not configured.
